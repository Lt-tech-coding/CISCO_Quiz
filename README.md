# CISCO_Quiz

A self-contained Cisco IT Essentials 8 study app by StealthxMedia.

## Open the quiz

Download `index.html` and open it in a current browser. No installation or build step is required. Questions, lessons, notes and images are embedded for offline use. Links to external references and promotions require internet access.

## Features

- Targeted practice with explanations, practical examples and review questions.
- Concept progress tracking across repeated question variants.
- Readiness tests with answers revealed after submission.
- Timers: 20 marks / 24 minutes, 50 marks / 60 minutes, 100 marks / 120 minutes.
- Saved sessions, numbered navigation, flags, module results and progress reset.
- Dark interface and attributed educational diagrams.

Progress is saved locally in each browser. The timer continues when leaving a session or refreshing the page.

This independent study tool is not affiliated with Cisco. Scores describe practice performance and do not confer certification.
